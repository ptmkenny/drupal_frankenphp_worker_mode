# How to use FrankenPHP Worker Mode in Drupal

This repo contains experimental code for getting Drupal to run on FrankenPHP's worker mode.

## Warning

- This is experimental. Optimistically, Drupal core needs 20+ commits to officially support FrankenPHP worker mode, and contrib will need even more.
- I tested on Drupal 12 alpha 1. This code will definitely not work on [anything less than 11.4 because it needs symfony/runtime](https://www.drupal.org/project/drupal/issues/3313404).

## AI Disclosure

I wrote this README, but a lot of this code was generated by AI and then edited by me. The code in this module is not suitable for upload to Drupal.org (it's sloppy); this is an experiment.

## What Works?

On my site, which has a 2-hour Behat test suite and a 30-minute Playwright test suite, all tests pass and everything works. However, I don't use every code module, so you may have some problems.

Some of the problems I experienced when working on this:

- Memory leaks (since worker mode reuses the kernel, even a small memory leak can quickly add up because every request leaks the same amount of memory)
- Data exposure (auth data being shown to anon users)

Needless to say these are really bad so don't use this in production.

If you find a worker-mode-related problem and open a core issue, add it to the [persistent app server](https://www.drupal.org/node/2218651) meta issue. If you open an issue or PR in this repo, I will add it to patches.json (core) or contrib.patches.json (contrib).

## Installation

[General Installation Instructions](https://www.drupal.org/docs/develop/local-server-setup/experimental-using-drupal-with-frankenphp-in-worker-mode)

You can use the `.ddev/` directory files to configure ddev.

## Repo Tools

- `patches.json`: A cweagans/composer-patches v2 patches.json with all the patches I am using for core to enable worker mode on my site. I used the Drupal.org issue MRs where available. Since this is experimental, I didn't copy the patch files locally; instead, I use the diff directly to have the latest. For patches that don't have issues yet (because I judged they will be hard problems to solve), I included local patches in `patches/`.
- `contrib.patches.json`: Patches for contrib modules that I use on my site. Contrib modules that use caching in their services will likely need to be patched to run under worker mode.
- `modules/frankenphp_profiler`: A profiler you can use to run XHProf in ddev.
